# Aditya Doppalapudi — Portfolio

Personal portfolio built with HTML, CSS, and JavaScript.

- [Live site](https://adidoppalapudi.github.io/)
- [Selected work](https://adidoppalapudi.github.io/work/)
- [Resume](https://adidoppalapudi.github.io/assets/files/resume.pdf)

The About page includes film and calligraphy activity logs. The Work page describes selected projects.

Shared styles, scripts, data, resume, and images live in `assets/`; page entry files remain at the repository root and in `work/`.

To preview locally, run `python -m http.server` from the repository root.
